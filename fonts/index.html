ADETAIL

Menlo’s line spacing, to the unit.

Meslo LG S adds 200 units to every line. Meslo Code takes them back out: ascent 1901, descent 483, the same numbers Menlo uses. The same code fills the same height as the font you are used to.

MESLO LG S superseded

2584 u
1.262 em 
fn main() {
    let v = vec![1, 2, 3];
    for x in &v {
        println!("{x}");
    }
}

MESLO CODE = Menlo

2384 u
1.164 em 
fn main() {
    let v = vec![1, 2, 3];
    for x in &v {
        println!("{x}");
    }
}

Six lines, two heights. The width does not change at all: every character is 1233 units wide in both, exactly like Menlo, so columns and alignment stay where they were.

BREVISIONS

Ligatures that keep the grid.

Each ligature is drawn across the cells of the characters it replaces, so -> still takes two columns and the cursor still stops between them. Large: the ligature (REV B). Small: the characters typed (REV A).

DASSEMBLY

Install in a minute.

Download the zip, install the four .ttf files, then pick Meslo Code in your editor and terminal. Close and reopen any app that was running.

macOS

Double-click each file and press Install, or:

cp MesloCode/*.ttf ~/Library/Fonts/

Linux

Copy to your fonts folder and refresh the cache:

mkdir -p ~/.local/share/fonts
cp MesloCode/*.ttf ~/.local/share/fonts/
fc-cache -f

Windows

Select the four .ttf files in MesloCode\, right-click and choose Install.

VS Code

The terminal does not inherit the editor font, so set both. Ligatures are off by default.

"editor.fontFamily": "'Meslo Code', Menlo, monospace",
"editor.fontLigatures": true,
"terminal.integrated.fontFamily": "'Meslo Code', Menlo, monospace",
"terminal.integrated.fontLigatures.enabled": true

Terminals

iTerm2Profiles → Text, check Use ligatures
Ghosttyfont-family = Meslo Code
kittyfont_family Meslo Code
WezTermwezterm.font 'Meslo Code'
Terminal.appfont only, no ligatures

Web pages

Copy MesloCode/web/ next to your site. Pages without icons download only the 36 KB Latin files.

<link rel="stylesheet" href="web/meslo-code.css">
<style> code, pre { font-family: "Meslo Code", Menlo, monospace; } </style>
